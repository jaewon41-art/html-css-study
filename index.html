왜 넘어가야 하나요?

  • 지금 방식(방법 1)은 페이지를 열 때마다 GitHub API에 파일 목록을 물어봐요. 같은 인터넷 주소에서 시간당 60번까지만 응답해서, 싸지방처럼 여러 명이 같은 주소를 쓰면 목록이 안 뜰 수 있어요.
  • 방법 2는 커밋할 때 GitHub 서버가 목록이 담긴 index.html을 미리 만들어 둬요. 횟수 제한이 없고 더 빨라요.
  • 자동 빌드·배포(CI/CD)는 실무와 다른 프로젝트에서도 계속 쓰는 개념이에요.

할 일 체크리스트

  1. 자바스크립트 기초(변수, 함수, 배열, fetch) 공부하기
  2. GitHub Actions와 YAML 문법 기초 알아보기
  3. .github/workflows/ 폴더에 목록 생성용 workflow 파일 만들기
  4. Settings → Pages에서 Source를 "GitHub Actions"로 바꾸기
