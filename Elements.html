문서 구조

모든 HTML 파일의 뼈대예요. 대부분 화면에는 안 보이고 브라우저에게 정보를 줘요.

HTML 문서 전체를 감싸는 가장 바깥 요소예요. lang 속성으로 문서 언어를 알려줘요.

화면에 안 보이는 정보(제목, 인코딩, CSS 연결 등)를 모아두는 곳이에요.

화면에 보이는 모든 내용이 들어가는 곳이에요. 이 페이지에서 보이는 것도 전부 body 안에 있어요.

브라우저 탭과 즐겨찾기, 검색 결과에 표시되는 제목이에요. 이 페이지 탭에 보이는 "HTML 요소 도감"이 title이에요.

문자 인코딩, 모바일 화면 크기, 페이지 설명 같은 정보를 적어요. 닫는 태그가 없어요.

외부 CSS 파일이나 파비콘(탭 아이콘)을 연결해요. 하이퍼링크인 <a>와는 달라요.

HTML 파일 안에 CSS를 바로 작성할 때 써요. 이 페이지의 디자인도 head 안 style에 들어 있어요.

자바스크립트 코드를 쓰거나 외부 .js 파일을 연결해요. 버튼 클릭 같은 동작을 만들 때 필요해요.

브라우저에서 자바스크립트가 꺼져 있을 때만 보여주는 내용이에요.

상대 경로 링크의 기준이 되는 주소를 정해요. 실제로는 거의 안 써요.

template 안의 내용은 화면에 안 나오고, 자바스크립트로 복사해서 쓰는 틀이에요. slot은 웹 컴포넌트에서 내용을 끼워 넣는 자리예요. 나중에 JS 배울 때 다시 보면 돼요.

영역 나누기

보기에는 div와 똑같지만, 이름만으로 "여기가 무슨 영역인지" 알려주는 요소들이에요. 결과 칸의 주황 점선이 각 영역이에요.

제목이에요. 숫자가 작을수록 큰 제목이고, 보통 한 페이지에 h1은 하나만 써요.

header는 머리말(로고, 제목), nav는 메뉴, main은 핵심 내용, footer는 꼬리말(저작권, 연락처)이에요.

비슷한 주제끼리 묶은 구역이에요. 보통 안에 제목(h2 등)을 넣어요.

그것만 떼어서 봐도 말이 되는 글이에요. 블로그 글, 뉴스 기사, 댓글 하나 등에 써요.

본문과 관련은 있지만 빠져도 되는 내용이에요. 사이드바, 광고, 참고 박스 등에 써요.

아무 의미 없이 묶기만 하는 상자예요. 위의 요소들 중 맞는 게 없을 때 쓰고, 주로 CSS로 꾸미기 위해 묶어요.

글쓴이나 사이트 운영자의 연락처예요. 기본적으로 기울임꼴로 보여요.

제목과 부제목을 하나로 묶어요.

검색창을 감싸는 영역이라고 알려주는 요소예요. 비교적 최근에 생겼어요.

글 덩어리

문단, 목록, 인용처럼 한 줄을 통째로 차지하는(블록) 요소들이에요.

문단이에요. 문단끼리는 자동으로 위아래 간격이 생겨요. 코드에서 엔터를 쳐도 화면에서는 한 줄로 이어져요.

br은 문단 안에서 줄만 바꿔요. hr은 주제가 바뀌는 곳에 가로선을 그어요. 둘 다 닫는 태그가 없어요.

ul은 순서 없는 목록(점), ol은 순서 있는 목록(숫자)이에요. 항목 하나하나는 li로 써요.

dt에 용어, dd에 그 설명을 쓰는 목록이에요. 사전이나 FAQ 같은 곳에 어울려요.

ul과 똑같이 보이지만 버튼 같은 '명령' 목록이라는 의미예요.

다른 곳에서 가져온 긴 글을 인용할 때 써요. 기본으로 들여쓰기가 돼요.

공백과 줄바꿈을 쓴 그대로 보여줘요. 코드나 아스키 아트에 써요.

이미지, 표, 코드 같은 자료와 그 설명(캡션)을 한 덩어리로 묶어요.

글자 꾸미기

문장 중간에 들어가는(인라인) 요소들이에요. 생김새가 비슷한 것끼리 묶어서 비교해 보세요.

다른 페이지나 같은 페이지의 특정 위치로 이동하는 링크예요. href에 주소를 써요. target="_blank"는 새 탭으로 열어요.

둘 다 굵게 보여요. strong은 "중요하다"는 의미가 있고, b는 의미 없이 눈에 띄게만 해요. 보통 strong을 써요.

둘 다 기울어져요. em은 말할 때 힘주는 강조, i는 외국어나 생각처럼 평소와 다른 목소리를 나타내요.

u는 밑줄(맞춤법 오류 표시 등), s는 더 이상 맞지 않는 내용에 긋는 취소선이에요.

문서가 수정된 기록을 남겨요. del은 지운 내용, ins는 새로 넣은 내용이에요. s와 달리 '수정 이력'이라는 의미예요.

형광펜으로 칠한 것처럼 표시해요. 검색어 강조 등에 써요.

주석, 저작권 표시처럼 덜 중요한 작은 글씨예요.

sub는 아래로 작게(화학식), sup는 위로 작게(제곱, 각주) 써요.

code는 코드 조각, kbd는 키보드 입력, samp는 프로그램 출력 결과, var는 변수 이름이에요. 대부분 고정폭 글꼴로 보여요.

abbr는 줄임말이에요. 마우스를 올리면 title의 전체 이름이 떠요. dfn은 그 문장에서 처음 정의하는 용어를 표시해요.

q는 문장 속 짧은 인용이라 따옴표가 자동으로 붙어요. cite는 책, 영화 같은 작품 제목이에요.

보이는 글자와 별개로 컴퓨터가 읽을 수 있는 값을 숨겨둬요. time은 날짜·시간, data는 그 밖의 값이에요.

div의 인라인 버전이에요. 문장 일부만 CSS로 꾸미고 싶을 때 묶어요.

아주 긴 단어에서 "칸이 모자라면 여기서 줄을 바꿔도 돼"라고 알려줘요. 결과 칸 폭을 줄여보면 차이가 보여요.

bdo는 글자 방향을 강제로 바꿔요. bdi는 아랍어처럼 오른쪽→왼쪽으로 쓰는 글이 섞여도 주변이 안 깨지게 분리해요.

한자나 일본어 위에 읽는 법을 작게 달아요. rp는 ruby를 지원 안 하는 브라우저에서만 보이는 괄호예요.

이미지·미디어

그림, 소리, 영상을 넣는 요소들이에요. 예제는 파일 없이 동작하도록 코드로 만든 그림을 썼어요. 실제로는 src에 "images/cat.jpg" 같은 파일 경로를 써요.

이미지를 넣어요. src는 파일 주소, alt는 이미지가 안 뜰 때나 화면 낭독기가 읽어주는 설명이에요. 닫는 태그가 없어요.

화면 크기 등 조건에 따라 다른 이미지를 보여줘요. 결과 칸이 있는 창 너비를 600px보다 줄이면 색이 바뀌어요.

이미지 위에 클릭할 수 있는 구역을 정해요. 그림 왼쪽 절반을 클릭하면 링크로 이동해요.

음악이나 소리를 재생해요. controls를 쓰면 재생 버튼이 보여요. 예제는 파일이 없어서 재생은 안 돼요.

영상을 재생해요. track으로 자막 파일(.vtt)을 연결해요. 예제는 파일이 없어서 빈 화면이에요.

자바스크립트로 그림을 그리는 빈 도화지예요. 게임이나 그래프에 써요. 아래 원은 이 페이지 맨 아래의 JS가 그린 거예요.

코드로 도형을 그려요. 확대해도 깨지지 않아서 아이콘에 많이 써요.

수학 수식을 표현해요 (MathML). 분수, 제곱 등을 제대로 된 수식 모양으로 보여줘요.

다른 콘텐츠 넣기

페이지 안에 다른 페이지나 파일을 끼워 넣는 요소들이에요.

다른 웹페이지를 창처럼 끼워 넣어요. 유튜브 영상이나 지도를 넣을 때 써요. 예제는 srcdoc으로 내용을 직접 넣었어요.

PDF나 그림 같은 외부 파일을 넣어요. object는 파일이 안 열릴 때 보여줄 대체 내용을 넣을 수 있어요. 요즘은 img, iframe을 더 많이 써요.

표

표는 여러 요소가 한 세트로 움직여서 하나의 예제로 모았어요. 테두리는 결과 칸에서만 CSS로 넣었어요(기본은 테두리 없음).

table: 표 전체 / caption: 표 제목 / thead·tbody·tfoot: 머리·몸통·꼬리 줄 묶음 / tr: 한 줄 / th: 제목 칸(굵게, 가운데) / td: 일반 칸. colspan은 칸을 가로로, rowspan은 세로로 합쳐요.

td를 하나하나 꾸미지 않고 세로줄(열) 단위로 한 번에 스타일을 줘요.

입력 폼

사용자에게 값을 입력받는 요소들이에요. 결과 칸에서 직접 눌러보고 입력해 보세요.

form은 입력 요소 전체를 감싸요. label은 입력칸의 이름표(누르면 입력칸이 선택돼요), input은 입력칸, button은 버튼이에요.

input은 type만 바꾸면 완전히 다른 입력칸이 돼요. 하나씩 눌러보며 비교해 보세요.

여러 줄을 입력하는 칸이에요. rows와 cols로 크기를 정해요.

select는 펼쳐서 고르는 목록, option은 선택지, optgroup은 선택지 묶음이에요.

입력칸에 글자를 치면 추천 목록이 떠요. 목록에 없는 값도 자유롭게 입력할 수 있다는 점이 select와 달라요.

관련 있는 입력칸들을 테두리로 묶고, legend로 그 묶음에 제목을 붙여요.

계산된 결과를 보여주는 칸이에요. 숫자를 바꿔보세요.

생김새는 비슷해요. progress는 '얼마나 진행됐나'(다운로드 등), meter는 '범위 안의 현재 값'(배터리, 저장 공간)이에요. meter는 값에 따라 색이 바뀌어요.
